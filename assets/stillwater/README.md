# Stillwater pictures

- `art/`: photographs of paintings made before 1930, in the public domain (see `tools/stillwater/src/01-data.js`, SW_ART).
- `world.jpg` (8 November 2026): the world map on the Map Room's globe and wall, drawn for the game from the coastlines of
  Natural Earth (public domain, https://www.naturalearthdata.com) as packaged in `world-atlas` 2.0.2 (ISC licence,
  Michael Bostock). The land colours (forests, grassland, deserts, ice) are painted by the game's own script, not a photo.
